# Foundational PMHNP Library

## Purpose

This folder is the first live research artifact produced through the repository harness. It inventories high-value psychiatric-mental health nurse practitioner reference material already available through the connected Google Drive and defines how those sources may be used in later research and writing.

This is **not** a clinical guideline, treatment protocol, or publication-ready evidence review.

## Operating model

1. Retrieve connected source material through Google Drive first.
2. Record enough metadata to re-find the source.
3. Distinguish `discovered`, `partially inspected`, and `inspected` sources.
4. Use reference texts primarily for orientation, terminology, conceptual framing, and locating higher-level evidence.
5. Re-verify publication-facing clinical claims against the best current authoritative source for the question: primary literature, systematic reviews/meta-analyses, guidelines, regulators, official labeling, professional organizations, statutes, or board rules.
6. Keep copyrighted source content in its original source system. Do not copy chapters, tables, or large excerpts into GitHub.
7. Do not add PHI or patient-identifiable material.

## Current source domains

The initial Drive-first inventory covers five foundational domains:

- PMHNP role, scope, certification, and broad clinical review;
- evidence-based-practice methodology;
- psychotherapy for advanced practice psychiatric nursing;
- psychopharmacology and neuroscience;
- child and adolescent psychiatric assessment.

## Files

- [`question.md`](question.md) — scope, decision boundaries, and evidence priorities.
- [`sources.md`](sources.md) — re-findable source log with inspection and publication-use status.
- [`evidence-map.md`](evidence-map.md) — maps each source to appropriate use cases and required external verification.

## Publication boundary

A source being present in Drive does not make it suitable as final authority for an external claim. Textbooks can become outdated, and some connected-file provenance may not be established from Drive metadata alone. Files whose names indicate non-publisher archive provenance require additional caution: they may be used for personal orientation, but the repository must not redistribute them and should verify publication-facing claims using lawful authoritative sources.

## Definition of done for this slice

This inventory is complete when the selected Drive sources are re-findable, duplicates are identified, source roles are explicit, provenance/use limitations are documented, and no source is represented as stronger or more current than the inspection supports.
