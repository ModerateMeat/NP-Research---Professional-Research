## Core operating rule

Use connected tools first. GitHub work should be performed through the GitHub connector and connected Google Drive material should be searched/read through the Drive connector whenever possible. Substantive work belongs on a short-lived branch and should reach `main` through a pull request.

Complex instructions belong in version-controlled Markdown files. Do not rely on giant terminal pastes, shell heredocs, or chat history as the durable source of truth for a task.
