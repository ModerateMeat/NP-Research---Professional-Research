# Workflow Templates

Use these files as durable starting points for research and writing work. Copy the relevant template into the project/topic folder, complete it there, and keep the resulting artifact under version control.

## Templates

- `SPRINT_BRIEF.md` — bounded multi-slice outcome plan.
- `RESEARCH_QUESTION.md` — question, scope, population/context, outcomes, and decision boundaries.
- `SOURCE_LOG.md` — inspected-source record with re-findable identifiers and verification status.
- `EVIDENCE_TABLE.md` — structured evidence extraction that separates reported findings from interpretation.
- `FACT_CHECK.md` — claim-by-claim citation, number, certainty, and wording verification.

## Operating rules

- Read `AGENTS.md` before using these templates.
- Use connected source systems first when relevant, especially Google Drive for material already stored there.
- Do not copy PHI or unnecessary sensitive source content into GitHub.
- Do not mark a source as inspected unless it was actually opened/read.
- Keep large instructions and research handoffs in Markdown files rather than terminal paste buffers or chat history.
- Complete substantive work on a short-lived branch and merge through a pull request.
